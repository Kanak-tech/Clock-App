# Clock App

A simple Clock App with a live clock, a countdown timer and a stopwatch. Built with HTML, CSS and JavaScript.

## Features
- Live digital clock with today's date
- Timer: set hours, minutes and seconds, then Start, Pause or Reset
- Stopwatch: Start, Stop and Reset with centiseconds

## Tech Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this project.
2. Open `index.html` in your browser.
3. Clock, Timer and Stopwatch are all shown on one page.
